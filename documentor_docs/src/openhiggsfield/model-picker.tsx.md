# Technical Documentation: `src/openhiggsfield/model-picker.tsx`

## Overview

The `ModelPicker` component is a React client component (`"use client"`) that renders an interactive popover dialog allowing users to browse, search, and select AI generation models. Models are scoped to a specific target surface context (e.g., image, video, audio generation) and can be searched by name, ID, or description.

---

## Props Interface

The `ModelPicker` function accepts a single object containing the following props:

| Prop | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `selectedId` | `string` | Yes | The ID of the currently active/selected model. |
| `surface` | `Surface` | Yes | The surface category (e.g., surface key) used to filter the model catalog. |
| `onPick` | `(model: ModelEntry) => void` | Yes | Callback function invoked when a user clicks on a model option. Receives the full `ModelEntry` object. |
| `onClose` | `() => void` | Yes | Callback function invoked when the user clicks the close button. |

---

## State and Refs

### React State

* **`search`** (`string`, initial value: `""`)  
  Stores the current search string typed into the input field.

### React Refs

* **`inputRef`** (`useRef<HTMLInputElement>(null)`)  
  References the search `<input>` element. Used to automatically focus the input field upon mount and when clearing search queries.
* **`listRef`** (`useRef<HTMLDivElement>(null)`)  
  References the scrollable container (`div.ohf-picker-list`) holding the list of models. Used to reset scroll position (`scrollTop = 0`) when a user types a new search query.

---

## Derived State & Filter Logic

1. **`query`**: Lowercased and trimmed version of the `search` state string.
2. **`catalog`**: Array of models filtered from global `MODELS` where `model.surface === surface`.
3. **`models`**: Array of models from `catalog` filtered by `query`. A model matches if `query` is empty OR if `query` is contained within the combined string:
   $$\text{`\${model.label} \${model.id} \${describeModel(model)}\`}$$

---

## Component Behavior & Features

### 1. Initial Render & Auto-Focus
When the component mounts, an effect hook (`useEffect`) triggers `inputRef.current?.focus()`, automatically shifting keyboard focus to the search input.

### 2. Search Input & Scroll Reset
Typing into the input updates the `search` state. On every `onChange` event, if `listRef.current` exists, its `scrollTop` property is explicitly set to `0`. This ensures that newly filtered results are scrolled back to the top of the list view.

### 3. Dynamic Catalog Header
The header section above the list (`div.ohf-pop-head.ohf-picker-group`) displays context-sensitive text:
* **With Active Search Query**: Displays `${models.length} of ${catalog.length} ${SURFACE_LABELS[surface].toLowerCase()} models`
* **Without Search Query**: Displays `${SURFACE_LABELS[surface]} models`

### 4. Empty Search State
If `models.length === 0` (no search results match):
* Renders an empty state block containing a search icon, a title specifying the current query (`No model matches “{search.trim()}”`), and catalog total context.
* Includes a **"Clear search"** button (`button.ohf-btn-solid`). Clicking this button resets `search` state to `""` and focuses the search input (`inputRef.current?.focus()`).

### 5. Model Row Rendering
Each model in `models` is rendered as an interactive `<button>` with class `ohf-model-row`:
* **Selection State**: Sets `aria-current={selected || undefined}` where `selected` is `model.id === selectedId`.
* **Icon / Visual Swatch**:
  * Evaluates `modelIconSrc(model.id)`.
  * **If an icon exists**: Renders `<ModelIcon modelId={model.id} size={18} />` inside a `.ohf-model-row-swatch--icon` container.
  * **If no icon exists**: Renders a fallback swatch span using a background color generated by `swatchFor(model.surface, model.id)` and a grain overlay (`span.ohf-grain`).
* **Label & Description**: Displays `model.label` and string output from `describeModel(model)`.
* **Selection Indicator**: Renders a `<CheckIcon />` if `selected` is `true`.
* **Selection Handler**: Invokes `onPick(model)` when clicked.

## UI Structure & CSS Properties

The root element provides accessibility roles and a custom CSS variable based on total surface models:

```tsx
<div
  className="ohf-popover ohf-popover--picker"
  role="dialog"
  aria-label="Models"
  style={{ "--ohf-picker-rows": catalog.length } as CSSProperties}
>
```

* **Role**: `role="dialog"` with `aria-label="Models"`.
* **CSS Variable**: `--ohf-picker-rows` is calculated from `catalog.length` (the total unfiltered count of models for the active surface).

## Dependencies & External Imports

* **`MODELS`**: Raw array catalog imported from `@/generation/catalog`.
* **`ModelEntry` & `Surface`**: TypeScript types imported from `@/generation/catalog`.
* **`swatchFor`**: Function imported from `./artwork` to generate background color styles for visual model swatches.
* **`SURFACE_LABELS` & `describeModel`**: Utility constants/functions imported from `./data`.
* **Icons (`CheckIcon`, `CloseIcon`, `SearchIcon`)**: SVG icon components imported from `./icons`.
* **`ModelIcon` & `modelIconSrc`**: Component and lookup function imported from `./model-icon` for model logo icons.
