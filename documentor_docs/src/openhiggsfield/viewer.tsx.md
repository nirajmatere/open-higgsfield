# Technical Documentation: `src/openhiggsfield/viewer.tsx`

The `Viewer` component is a Next.js client-side modal dialog (lightbox) designed to display detailed output records (`RunRecord`) generated by AI models. It provides media rendering (images and videos), metadata details, clipboard integration, keyboard navigation, download management with fallback handling, and user actions (recreating, favoriting, and deleting runs).

---

## Constants & Utilities

### Module Constants

* **`EXIT_TIMEOUT_MS = 420`**: A timeout backstop (420 ms) used during modal exit transitions. It ensures that action callbacks fire even if the CSS `animationend` event fails to trigger (e.g., when the browser tab is backgrounded).
* **`COPIED_MS = 1600`**: Duration (1600 ms) for displaying the "Copied" confirmation state on the prompt copy button before reverting to default.
* **`CREATED`**: An `Intl.DateTimeFormat` instance configured with medium date styling (`dateStyle: "medium"`) and short time styling (`timeStyle: "short"`) for displaying precise generation timestamps.

### Helper Functions

#### `shapeOf(media: HTMLImageElement | HTMLVideoElement): number | null`
Calculates the numerical aspect ratio (`width / height`) of an image or video HTML element.
* For `HTMLVideoElement`, it inspects `videoWidth` and `videoHeight`.
* For `HTMLImageElement`, it inspects `naturalWidth` and `naturalHeight`.
* Returns `width / height` if both dimensions are greater than zero; otherwise, returns `null`.

## Component API: `Viewer`

### Props Interface

```typescript
{
  item: RunRecord;
  onClose: () => void;
  onReuse: () => void;
  onFavorite: () => void;
  onDelete: () => void;
  onPrev?: () => void;
  onNext?: () => void;
}
```

* **`item`**: The `RunRecord` object containing run details (prompt, media URLs, model metadata, ratio, settings, etc.).
* **`onClose`**: Function invoked when closing or dismissing the viewer modal.
* **`onReuse`**: Function invoked when selecting "Recreate", passing the run configuration back to the composer.
* **`onFavorite`**: Function invoked when toggling the favorite state of the current run.
* **`onDelete`**: Function invoked to delete the current run.
* **`onPrev`** *(optional)*: Callback for navigating to the previous item in the scope.
* **`onNext`** *(optional)*: Callback for navigating to the next item in the scope.

## Internal State & Refs

* **`ref`**: Ref attached to the native `<dialog>` element.
* **`panelRef`**: Ref attached to the inner panel container (`.ohf-dialog-panel`). Focused upon mounting to prevent action buttons from receiving immediate focus rings.
* **`closing`** (`boolean`): State indicating whether the modal is executing its exit animation sequence.
* **`copied`** (`boolean`): State tracking whether the prompt text was successfully copied to the clipboard.
* **`after`**: A `useRef` holding the pending callback function (defaults to `onClose`) to execute after the exit animation completes.
* **`save`**: State object (`{ id: string; state: "saving" | "failed" } | null`) tracking asynchronous media download operations for a specific run ID.
* **`delivered`** (`number | null`): State tracking the actual measured aspect ratio of loaded media, overriding the requested aspect ratio once known.
* **`shown`**: Render-phase state used to track changes in `item.id`. When `item.id` changes (such as when stepping through items using `onPrev`/`onNext`), `delivered` is reset to `null` and `copied` is reset to `false`.

## Core Operations & Logic Flow

### Modal Lifecycle & Focus Management

1. **Mounting**: On initial render, `useEffect` opens the modal via `ref.current?.showModal()` and focuses `panelRef.current`.
2. **Keyboard Navigation (`onKeyDown`)**:
   * **Left/Right Arrow Keys**: Triggers `onPrev` or `onNext` unless the event target is an `HTMLVideoElement` (allowing default video scrubbing) or the modal is in the process of `closing`.
   * **Escape Key (`onCancel`)**: Intercepted using `event.preventDefault()` to trigger the animated `leave(onClose)` transition instead of immediate native dismissal.
3. **Stage Click Dismissal**: Clicking directly on the stage overlay (`.ohf-viewer-stage`) triggers `leave(onClose)`.

### Animated Exit Pattern (`leave`)

To prevent cutting off closing CSS animations, the dialog remains mounted while animating:
1. `leave(action)` sets `after.current = action` and updates `closing` state to `true`.
2. The outer container sets `data-closing="true"`.
3. Dismissal triggers when the CSS animation ends (`onAnimationEnd` on `.ohf-viewer-panel`).
4. **Fallback Safety**: A `setTimeout` bound to `EXIT_TIMEOUT_MS` ensures `after.current()` is invoked if `onAnimationEnd` fails to fire.

### Clipboard Interaction (`copyPrompt`)

Invokes `navigator.clipboard.writeText(item.prompt)`. If resolved, sets `copied` state to `true` for `COPIED_MS` (1600ms). If rejected, `copied` is set to `false`.

### Aspect Ratio Measurement (`measure`)

When media mounts or loads (`onLoad` for images, `onLoadedMetadata` for videos):
1. `measure` is called with the HTML element ref/target.
2. `shapeOf` calculates the natural width and height.
3. If valid, `delivered` is set to the real calculated aspect ratio.
4. The CSS property `--a` and standard `aspectRatio` inline styles on `.ohf-viewer-figure` are updated accordingly.

### File Download and CDN Fallback

1. When the download link is clicked, default navigation is prevented unless `saveState === "failed"`.
2. `save` state changes to `{ id: item.id, state: "saving" }`.
3. `saveFile(url, fileNameFor(item, 0))` fetches the file as a Blob.
4. **Success**: `save` state resets to `null`, and the browser saves the Blob.
5. **CDN Refusal / Failure**: `save` state becomes `{ id: item.id, state: "failed" }`. The UI changes the button to "Open file" (`OpenOutIcon`), adds `target="_blank"`, and shows an error message. Clicking again allows standard browser navigation to open the raw CDN URL in a new tab.

## Structure & Layout

```
<dialog> (Native modal wrapper, captures escape/arrow keys)
 └── <div.ohf-dialog-panel.ohf-viewer-panel> (Focus container & animation target)
      ├── <div.ohf-viewer-stage> (Stage backdrop, click to dismiss)
      │    └── <figure.ohf-viewer-figure> (Main display area, styled with calculated dynamic aspect ratio)
      │         ├── <span.ohf-viewer-art> (Background artwork fallback layer)
      │         ├── <video> | <img> (Media element measured on attach/load)
      │         └── <span.ohf-grain> (Fallback if no media URL exists)
      │
      └── <aside.ohf-viewer-side> (Sidebar container)
           ├── <header.ohf-viewer-side-head>
           │    ├── Model Icon & Model Label
           │    ├── Relative time ago (via timeAgo)
           │    └── Close button
           │
           ├── <div.ohf-viewer-side-body>
           │    ├── Prompt Section (Prompt text + Copy button)
           │    └── Details Section (Model name, formatted settings/meta facts, full created date)
           │
           └── <footer.ohf-viewer-side-foot>
                ├── Recreate CTA button (invokes leave(onReuse))
                ├── CDN Failure Warning Message (conditional)
                └── Button Row:
                     ├── Download / Open file link button
                     ├── Delete button (invokes leave(onDelete))
                     └── Favorite toggle button (invokes onFavorite)
```
